# MAWA operating playbook

## How to work

1. Read `mawa status` and `mawa next`.
2. Load only the context named by `mawa context`.
3. Produce or review the artifacts of the current stage.
4. Show the human what will be approved and wait for confirmation.
5. Run `mawa audit` before declaring work complete.

## Limits

MAWA organizes decisions, evidence, and approvals. It does not replace human judgment, approve its own work, or execute arbitrary shell commands.
